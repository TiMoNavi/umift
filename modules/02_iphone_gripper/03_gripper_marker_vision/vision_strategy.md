# 夹爪视觉开合估计

这个目录单独讨论一件事：

- 如何从夹爪上的 iPhone 画面里，估计夹爪开合度

它和主采集链路分开，是因为这里的问题不只是“录下来”，而是“怎样把毫米级开合量稳定读出来”。

## 1. 先说结论

当前最推荐的第一版路线是：

1. iPhone 继续负责主采集：
   - RGB
   - Depth
   - 6DoF pose
2. 夹爪开合度单独走视觉估计
3. 第一版优先做 `marker-based`，不要一开始就赌 `markerless`

原因很简单：

- `ARKit` 对相机 6DoF pose 很有用
- `ARKit scene depth` 对近距离、细长边缘、反光材料的夹爪开口测量不够稳
- 如果目标是尽快拿到可用的 `gripper_width_m`，加标记比纯视觉分割稳得多

## 2. ARKit 到底有没有用

有用，但不是主测量通道。

### 2.1 有效的部分

- 相机位姿
- 世界坐标系建立
- 录制过程中的时间同步
- 提供一个可复现的 `session_world`

### 2.2 不应单独依赖的部分

- 直接用 `sceneDepth` 测夹爪开口宽度
- 直接靠 ARKit 对夹爪尖端做稳定几何定位

原因：

- 夹爪通常有细边、遮挡、金属反光、黑色塑料、快速运动
- iPhone 的深度通常经过平滑，边缘会糊
- 开口宽度真正关心的是两侧尖端之间的小距离，对边缘精度很敏感

所以结论是：

- `ARKit` 适合做 pose 和辅助约束
- `gripper_width_m` 的主读数，建议走 RGB 视觉几何

## 3. 要不要贴标记

如果目标是尽快得到稳定结果，建议贴。

### 3.1 推荐

在左右夹爪各贴一个高对比度、已知尺寸的视觉标记，例如：

- 小尺寸 AprilTag / ArUco
- 黑白矩形块
- 高对比色圆点对
- 两侧几何形状明确的细长贴纸

### 3.2 为什么推荐贴

- 检测更稳
- 对光照变化更不敏感
- 更容易从像素距离转成真实距离
- 更容易做自动质量评分

### 3.3 不贴也能不能做

能做，但难度会明显上升。

不贴标记时，一般要做：

- 夹爪边缘检测
- 尖端关键点定位
- 遮挡处理
- 运动模糊处理
- 不同材质和背景下的鲁棒性处理

这更像第二阶段，而不是第一阶段。

## 4. 推荐三条路线

### 路线 A：Marker-based 宽度估计

这是第一推荐。

做法：

1. 左右夹爪各贴一个已知尺寸标记
2. 在每帧 RGB 中检测左右标记中心或特征角点
3. 计算两标记之间的像素距离
4. 用相机内参和固定安装外参，把像素距离换成真实宽度
5. 输出：
   - `gripper_width_m`
   - `confidence`
   - `status`

优点：

- 最稳
- 标定简单
- 容易快速落地

### 路线 B：Markerless 边缘 / 关键点法

这是第二阶段路线。

做法：

1. 对夹爪两侧做检测或分割
2. 找到左右尖端或内侧边缘
3. 估计开口宽度

优点：

- 不改硬件外观

缺点：

- 训练和调参成本更高
- 对背景、反光、遮挡更敏感

### 路线 C：ARKit depth 辅助宽度估计

只建议当辅助。

做法：

1. 在 RGB 里找到左右 ROI
2. 用 ARKit depth 辅助筛掉错误边缘
3. 不把 depth 当唯一真值

优点：

- 可以帮助做遮挡判断和粗深度过滤

缺点：

- 边缘精度通常不够
- 近距离夹爪几何容易被平滑

## 5. 第一版建议怎么做

最现实的第一版建议：

1. 贴标记
2. 固定 iPhone 相对夹爪的安装姿态
3. 录一批不同开合度样本
4. 建立：
   - 图像中左右标记距离
   - 真值夹爪宽度
5. 先做一个几何回归或线性 / 二次标定

这时甚至不一定需要复杂模型，可能一条标定曲线就够用。
