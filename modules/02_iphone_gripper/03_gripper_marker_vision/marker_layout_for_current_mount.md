# 当前安装视角下的 Marker 贴法建议

本文件基于当前同步到电脑的两张真实参考图：

- `IMG_0022`：完全闭合
- `IMG_0021`：100% 张开

## 1. 视角结论

从这两张图能直接看出几个事实：

1. 相机视角非常固定，而且是从夹爪上方向前看
2. 真正进入画面的夹爪区域只占画面最下方一小条
3. 张开和闭合时，最稳定可见的是左右两个爪子的上表面和靠内侧前段
4. 纯靠轮廓、边缘、尖端距离去做宽度估计会很脆弱

所以第一版不建议：

- 只靠 orange 边缘做分割
- 只靠 gap 宽度做像素测量
- 只靠 ARKit depth 读开口

## 2. 第一推荐贴法

### 2.1 推荐位置

左右夹爪各贴一个小 `ArUco`，优先贴在：

- 每个爪子顶部、靠近前端、朝向相机的平面
- 如果夹爪本体已经有官方或结构上的 marker 规定点，优先直接使用那个规定点

也就是：

- 你当前照片里最稳定可见的那两个“上表面”区域

原因：

- 这个平面最接近正对相机
- 在张开和闭合两种极端姿态下都能看到
- 不依赖夹爪中间缝隙是否露出来
- 比贴在内侧竖直面上更不容易互相遮挡

对于你刚说的“夹爪上本来就有贴标记的规定点”，我的建议是：

1. 优先用规定点
2. 如果规定点正好在这两个顶部前段可见平面上，直接按规定点贴
3. 如果规定点位置偏后、偏斜、或者容易被夹爪机构遮挡，再考虑加一个小平片把 marker 抬到更正对相机的位置

## 3. 不推荐位置

不建议第一版贴在：

### 3.1 两个爪子正对彼此的内侧面

原因：

- 闭合时容易相互遮挡
- 开合过程中视角变化敏感

### 3.2 夹爪根部

原因：

- 根部相对位移小
- 对开合度不够敏感

### 3.3 强反光金属裸面

原因：

- 会显著降低检测率

## 4. marker 大小建议

先按下面优先级试：

1. `16 mm` 方形 ArUco
2. 如果规定点面积不够，再退到 `12 mm`
3. 再不行才考虑 `10 mm` 或更小

但要注意：

- 太小会让远端检测率下降
- 太靠边会导致出画

所以最稳的第一轮测试是：

- 左右各一个
- 优先 `16 mm`
- 打印高对比黑白
- 外面保留白边

推荐左右分配：

- 左夹爪：`ArUco id 0`
- 右夹爪：`ArUco id 1`

字典：

- `DICT_4X4_50`

## 5. 朝向建议

左右两个 marker 建议：

- 都保持边与夹爪边缘平行
- 不要一个斜贴一个正贴

这样有两个好处：

1. 更容易稳定检测
2. 后续调试时，左右 marker 的姿态异常更容易看出来

## 6. 如果顶部平面不够贴

如果你实物上发现顶部平面放不下足够大的 ArUco，第一备选是：

- 在每个爪子顶部或外侧前端粘一个小的“抬高平片”
- 再把 ArUco 贴在这个平片上

也就是做一个很小的 marker mounting tab。

这样会比硬贴在弯曲/反光/过窄表面上更稳。

## 7. 第一版实施建议

建议按这个顺序做：

1. 先按规定点打印并贴 `16 mm` 的左右 ArUco
2. 拍闭合 / 半开 / 全开三种静态图
3. 看检测率、遮挡和出画情况
4. 如果规定点放不下或遮挡明显，再退到 `12 mm`
5. 还不稳的话，再决定是否需要：
   - 缩小 marker
   - 改位置
   - 加 mounting tab

## 8. 对当前项目的建议结论

对于你这套真实安装方式，我建议第一版就定成：

- `ArUco marker-based`
- 左右各一个
- 贴在左右爪顶部前段、正对相机的可见平面
- 必要时加一个小平片作为载体

这比 markerless 更现实，也更接近 UMI 已经验证过的路线
