# DEDH-75D-50NX6 规格摘要

下面这些是已经能从说明书文本里确认的事实。

## 型号与量程

- 型号：`DEDH-75D-50NX6`
- 力量程：`Fx/Fy/Fz = 50N / 50N / 50N`
- 力矩量程：`Tx/Ty/Tz = 2Nm`

这说明你买的是这一系列里量程最低的一档，更适合作为小力段标定参考。

## 电气与通信

- 供电：`9-36V DC`, `<1W`
- 接口：`RS485`
- 默认协议：`Modbus-RTU`
- 额外协议：`主动发送协议`
- 出厂默认：`115200`, `N81`, `地址 1`

说明书原文还能确认：

- `Modbus-RTU` 适合参数设置、清零、校准
- 高频实时采集更适合走“主动发送协议”
- 主动发送时，一路 `RS485` 串口只接一只传感器更稳妥

## 速度与精度

- 测量速度：说明书可确认 `40次/s` 和 `640次/s`
- 主动发送速率：可到 `640/s`
- 分辨率：`20位分度`
- 非线性：`优于 0.2%FS`
- 精度：`优于 0.3%FS`
- 重复性：`优于 0.2%FS`
- 耦合精度：`优于 2%FS`

## 对 CoinFT 校准的意义

这只 DEDH 不是 ATI 那种“模拟桥 + DAQ”路线，而是：

```text
数字六维力传感器
-> RS485
-> Modbus / 主动发送
-> 上位机直接读出 Fx/Fy/Fz/Mx/My/Mz
```

所以它可以当 CoinFT 的参考真值来源，但接入方式要改。

不能直接照搬的部分主要有：

- `nidaqmx`
- `Dev1/ai0:5`
- ATI 标定矩阵 `ATI_CAL_MAT`
- NI 数字同步线 `port0/line1`
