# 力控数据采集设备基本操作说明

本文档面向力控数据采集设备的现场操作者，说明设备组成、开始前准备、校准、单臂与双臂采集方法、力觉使用限制及异常数据判定。本文档仅介绍正常采集所需的基本操作，不展开软件部署、数据格式及程序调试方法。

使用本设备前，应确保笔记本端采集程序和 iPhone App 已完成安装，CoinFT 已完成传感器标定，各部件安装位置与标定时保持一致。

## 1. 设备组成与使用方式

本设备由手持采集端、全局视觉和笔记本端三部分组成。操作者通过手持夹爪完成抓取、放置、插入、擦拭等操作；系统同步记录夹爪第一视角、全局视角、夹爪位姿、夹爪开度以及左右指端力觉信息。

| 组成部分   | 主要部件                                         | 主要作用                                            |
| ---------- | ------------------------------------------------ | --------------------------------------------------- |
| 手持采集端 | iPhone、3D 打印夹爪、左右两个 CoinFT、Teensy 4.1 | 采集第一视角、六自由度位姿、夹爪开度及左右指端力觉  |
| 全局视觉   | D435/D435i RGB-D 相机                            | 从固定视角记录工作区 RGB 和深度信息                 |
| 笔记本端   | 采集程序、网页状态界面和数据存储目录             | 连接各路设备、显示实时状态并管理 Dataset 和 Episode |

单臂采集使用一套手持采集端，由操作者单手完成任务。双臂采集使用两套结构相同的设备，分别编号为 `left` 和 `right`，由操作者双手协同操作。每套设备内部均包含左右两个 CoinFT，因此“左右指端”表示同一个夹爪的两侧手指，不等同于双臂系统中的左右设备。

## 2. 开始前准备

正式通电前应先检查设备结构、线缆和采集场景。准备阶段完成后，采集过程中不应再移动全局相机、调整手机支架或改变指端结构。

### 2.1 结构与场景检查

1. 检查 iPhone、夹爪、CoinFT 和指端固定件，确认无松动、变形或异常挤压。
2. 清洁手机镜头、夹爪 marker 和 D435/D435i 镜头，确保没有污渍或遮挡。
3. 将线缆沿把手后方固定，并保留足够的手腕活动余量。移动和转动夹爪时，线缆不得牵拉 CoinFT，也不得扫过目标物体。
4. 固定 D435/D435i，使其能够看到完整工作区、目标物体和手持设备的主要运动范围。采集过程中不得移动相机。
5. 保持照明稳定、均匀，避免阳光直射、镜面强反光以及录制过程中突然开关灯。
6. 场景中应保留桌面纹理、物体边缘、文字或其他稳定视觉特征。手机画面不应长时间仅包含白墙、纯色桌面、天花板或无纹理角落，否则可能造成 ARKit 跟踪不稳定。
7. 双臂模式应核对两套设备的 `left/right` 标签，确保设备编号与实际握持手一致。

### 2.2 接线与启动

按以下顺序连接并启动设备：

1. 将 D435/D435i 连接笔记本。
2. 将 Teensy/CoinFT 连接笔记本，确认传感器线缆未受拉、未被结构件夹住。
3. 将 iPhone 通过 USB 连接笔记本，解锁手机并信任当前电脑。
4. 双臂模式按相同方式连接第二套手持采集端。
5. 启动电脑端采集程序，在浏览器中打开状态页面。
6. 新建或选择正确的 Dataset，然后点击 `Arm All`。

`Arm All` 用于启动并连接 iPhone、D435 和 CoinFT，使各路设备进入待录制状态；该按钮不会开始一条正式 Episode。正式 Episode 只能通过 iPhone 端录制按钮开始。

![Arm All 后的电脑端多路状态](assets/hardware_design/web_arm_all_live.png)

图 2 点击 `Arm All` 后的电脑端多路状态

进入校准前，应在电脑页面确认 iPhone 和 D435/D435i 画面持续更新，CoinFT Left/Right 曲线连续且空载状态下无明显饱和，同时核对 Dataset 名称及单双臂设备编号。任一路画面冻结、设备未连接或力觉读数异常时，不得开始正式录制。

## 3. 校准并进入 Ready

每次设备启动或安装位置发生变化后，均应完成力觉清零、夹爪开度校准和世界坐标标定。校准期间不得改变手机相对夹爪的位置。

1. 握住设备把手，使夹爪悬空且不接触任何物体，执行 CoinFT tare/清零。清零时不得按压或托住指端。
2. 在 iPhone 端进入夹爪校准，稳定完成“全开—全闭—全开”的完整行程。当前 App 完成至少 3 个完整循环后可进入下一步，正式采集建议完成 5～10 个循环，以覆盖完整开度范围。
3. 每次循环均应到达真实全开和全闭位置，但不得在机械限位处继续用力挤压；校准过程中两个 marker 应始终清晰可见。
4. 将手机朝向具有纹理的工作台平面，使画面中心十字对准选定的世界原点，待 ARKit 跟踪稳定后点击 `标记原点`。
5. 保持设备短暂静止，等待 iPhone 显示 `READY` 和 `Ready / Calibrated`。
6. 返回电脑页面，确认 `Gate` 为 `ready`，iPhone、D435 和左右 CoinFT 数据仍在持续更新。

## 4. 正式采集操作

一条完整 Episode 应连续包含动作前状态、接近、接触或抓取、任务操作、释放以及退出接触。UMI 类设备允许按照任务的自然速度采集，不要求操作者全程刻意慢速移动；但在接近目标和建立接触前必须主动减速，避免冲击、跟踪跳变和关键画面模糊。

### 4.1 握持方法

操作者应握住夹爪后方把手，使手掌和手指位于手机镜头后方，不遮挡镜头、marker 和指端。操作前应预先确定接近方向和手腕姿态，尽量通过连续的平移和转动完成任务，避免突然翻腕、快速反向、反复抖动或无任务意义的修正动作。

### 4.2 Episode 操作过程

| 阶段       | 操作要求                                                                                                                   | 应避免的情况                                                         |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 动作前     | 将夹爪置于规定起始位置，使目标和夹爪前端进入手机画面；点击 iPhone 录制按钮，倒计时结束并进入`Recording` 后保持约 1～2 秒 | 一按录制就立即快速移动；开始时已经接触或夹住物体                     |
| 接近       | 自由空间内按自然任务速度移动；接近目标时逐渐减速，并使目标、指端或预计接触区域保持可见                                     | 镜头转向无关区域；目标长时间出画；快速翻腕造成运动模糊               |
| 建立接触   | 对准目标后低速接近，确认指端接触，再逐步增加夹持力或外部接触力                                                             | 用夹爪敲击物体；尚未对准就闭合；一次性猛压至较大力值                 |
| 持续操作   | 使用完成任务所需的最小有效力连续操作；抓取只需夹稳，擦拭、插入等任务应平稳建立并维持接触力                                 | 无必要地增大力；接触中突然改变姿态；反复离开后重新碰撞目标           |
| 释放与退出 | 物体到达目标位置后先稳定放置，再完全松开夹爪并退出接触；保持约 1～2 秒后结束录制                                           | 物体尚未稳定即松手；释放和停止录制发生在同一瞬间；未记录退出接触过程 |

### 4.3 视野、遮挡与跟踪要求

采集过程中，手机无需始终机械地正对物体中心，但关键操作阶段必须保留足够的视觉上下文。接近、接触、抓取、释放等阶段，画面中至少应清楚看到目标物体、夹爪指端或当前接触区域。

腕部视角距离目标较近，短时、不可避免的局部遮挡可以接受，但接触区域不能在关键阶段持续不可见。操作者应将手掌保持在镜头后方，并避免身体长时间挡住 D435/D435i。双臂操作时，还应避免一套设备长期遮挡另一套设备的主要接触区域。

不要为寻找视角而快速、大角度翻转设备。若任务面对纯色或低纹理表面，应让手机画面同时包含表面边缘、文字、桌面物体等稳定特征。采集中如出现 ARKit 跟踪丢失、位姿瞬间跳变、画面严重模糊、marker 持续识别失败或相机画面冻结，应立即结束当前 Episode，并在状态恢复后重新采集。

### 4.4 力觉操作限制

> **推荐工作力：任一指端三轴合力不超过 10 N；任一指端绝对不得超过 50 N。** 设备用于记录自然操作中的接触力，不用于冲击、撬动或极限载荷测试。

正常任务应以能够完成操作的最小有效力为准，不建议反复或持续采集超过 `10 N` 的动作。确有较大接触力需求时，应缓慢增加力并持续观察曲线。任一指端接近 `50 N`、曲线饱和或出现明显冲击峰值时，应立即停止施力并结束当前 Episode。

**严禁移动、拆卸或自行调整 CoinFT。** CoinFT 传感器本体没有独立保护外壳，其安装位置、受力状态以及固定螺钉的松紧程度均有严格要求。传感器位置或螺钉预紧力的细微变化，都可能在传感器内部形成额外载荷，导致力觉零点偏移和测量值变化。操作者不得触碰 CoinFT 本体、松紧固定螺钉或改变指端安装关系。确需拆装时，必须由维护人员完成，并在重新安装后重新进行传感器标定。

不得用夹爪敲击桌面或物体，不得快速撞击、侧向撬动，也不得通过扭转或拉拽线缆施力。发生超力或冲击后，应检查 CoinFT 固定件、指端结构和空载零点；如零点明显漂移，应重新 tare，必要时停止使用并检查传感器。

采集过程中如发现夹爪完全空载时 CoinFT 读数不为 `0 N` 或出现明显零点偏移，应立即停止当前操作。若 iPhone 正在录制，应先结束当前 Episode 并将其判为无效；随后在电脑端依次点击 `Stop` 和 `Arm All`，重新启动并清零力觉数据流。恢复后应再次确认空载读数接近 `0 N`，方可继续采集；若重置后仍不归零，不得继续使用或自行调整传感器。

## 5. 单臂与双臂操作

### 5.1 单臂操作

单臂采集使用一套设备，由同一只手连续完成一条 Episode。另一只手不得进入主要视野，也不得在任务中扶正、移动目标物体或辅助夹爪操作。采集中途不得换手或调整手机支架。

若夹爪滑落、目标被另一只手移动、设备发生碰撞或力觉读数明显异常，应结束当前 Episode 并重新采集。

### 5.2 双臂操作

双臂采集使用两套相同设备：左手握持 `left` 设备，右手握持 `right` 设备。两套设备共同使用同一任务和 Episode 标识，基本握持、视野和力觉要求与单臂模式一致。

录制前必须确认两侧均已完成校准并进入 Ready，且两侧手机画面、全局视野和四路指端力觉均正常。倒计时结束后再开始双手动作，物体交接、共同接触和相互避让应在同一 Episode 内连续完成。任一侧掉线、持续遮挡、发生结构碰撞或异常受力时，两侧均应停止，该 Episode 应作为异常数据重新采集。

## 6. Episode 结束、异常判定与停机

### 6.1 正常结束一条 Episode

1. 完成任务，释放物体并使夹爪退出接触。
2. 保持动作结束状态约 1～2 秒，在 iPhone 端点击红色 `Terminate/停止` 按钮。
3. 等待 iPhone 返回 `Ready`，并确认电脑端出现 `record_stop_committed`，表示当前 Episode 已完成写入。
4. 简单检查录制时长、手机与全局画面、夹爪开度和 CoinFT 曲线是否正常。
5. 继续采集同一 Dataset 时，可直接从 iPhone 开始下一条 Episode，无需重复点击 `Arm All`。

浏览器中的 `Stop` 用于关闭整套采集设备、切换 Dataset 或结束当天采集，不能代替 iPhone 端的 Episode 停止按钮。

### 6.2 无效 Episode 判定

出现以下任一情况时，即使任务表面上已经完成，该 Episode 也应判为无效并重新采集：

- 关键接触阶段目标、指端或接触区域持续离开手机画面。
- ARKit 跟踪丢失，或夹爪位姿出现明显不连续跳变。
- marker 持续识别失败，导致夹爪开度缺失或明显跳变。
- 发生敲击、跌落、结构碰撞、CoinFT 饱和、明显冲击或超过力限制。
- 任一路设备掉线、画面冻结，或关键视觉、位姿、开度、力觉信息缺失。
- 单臂任务使用另一只手辅助；双臂任务有一侧未进入 Ready 或中途失效。
- 操作失败后仍在同一 Episode 内反复补救，产生与正常任务流程不一致的多余动作。
- Episode 未完整记录接近、接触或抓取、任务操作、释放和退出接触过程。

### 6.3 常见异常处理

| 现象                        | 处理方法                                                                                                                  |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| iPhone 或 D435/D435i 无画面 | 停止当前操作，检查 USB、手机解锁状态和设备连接，再重新点击`Arm All`                                                     |
| CoinFT 一侧无曲线或读数饱和 | 立即停止施力，检查接线和结构挤压，恢复空载后重新 tare                                                                     |
| CoinFT 空载读数不为`0 N`  | 先结束当前 Episode，再依次点击电脑端`Stop` 和 `Arm All`；确认空载读数恢复后重新采集，仍不归零时停止使用并联系维护人员 |
| `Gate` 未显示 `ready`   | 检查世界坐标标定、设备在线状态和数据新鲜度，不得绕过 Gate 录制                                                            |
| 双臂仅一侧正常              | 两侧均停止，检查设备编号与连接，重新初始化后再录制新 Episode                                                              |
| 操作中超过力限制或发生碰撞  | 立即结束 Episode，检查夹爪结构和 CoinFT 零点，并将本条数据判为无效                                                        |

### 6.4 结束采集与停机

当天采集结束时，应先确认当前 Episode 已正常结束并完成写入，再停止整套设备：

1. 确认 iPhone 已退出 `Recording` 并返回 `Ready`。
2. 确认电脑端最后一条 Episode 已出现 `record_stop_committed`。
3. 点击浏览器 `Stop`，停止 iPhone、D435/D435i 和 CoinFT 数据流。
4. 关闭采集程序，再依次断开 iPhone、Teensy/CoinFT 和 D435/D435i。
5. 将夹爪放置在无外力、无线缆拉扯的位置，检查指端、手机支架和传感器固定件是否松动。
6. 记录当天出现的掉线、超力、碰撞和重新校准情况，供后续数据筛选使用。

若按上述简要处理仍不能恢复设备，应停止采集并交由维护人员检查，不应在现场反复拔插或自行拆卸 CoinFT。
